Таким образом, json-схема продукта (обозначим её `<product-json>`):

```json
{
  "id": 0,
  "name": "string",
  "description": "string"

     {
       "name": "string",
       "description": "string"
     }
     ```

   - `GET /product/{product_id}`

   - Схема ответа: `<product-json>` (обновлённый продукт)

   - `DELETE /product/{product_id}`
   - Схема ответа: `<product-json>` (удалённый продукт)
5. Получить список всех продуктов 
   - `GET /products`  
   - Схема ответа:
     ```
     [ 
       <product-json-1>,
       <product-json-2>, 
       ... 
     ]
     ```

Предусмотрите возвращение ошибок (например, если запрашиваемого продукта не существует).

Вы можете положить код сервиса в отдельную директорию рядом с этим документом.

## Задачи

### Задача 1 (2 балла)
Общая (сквозная) задержка прохождения для одного пакета от источника к приемнику по пути,
состоящему из $N$ соединений, имеющих каждый скорость $R$ (то есть между источником и
приемником $N - 1$ маршрутизатор), равна $d_{\text{сквозная}} = N \dfrac{L}{R}$
Обобщите данную формулу для случая пересылки количества пакетов, равного $P$.

#### Решение
Если считать, что хост может одновременно передавать один пакет и принимать другой, то клиент (начало цепочки) сможет начать передавать следующий пакет сразу после предыдущего. Первые $P-1$ пакетов он передаст за $\dfrac{L}{R}$ времени каждый. После этого он начнёт передавать последний пакет, и на сервере (конце цепочки) он окажется ещё через $N \dfrac{L}{R}$ времени. Всего $(P-1+N) \dfrac{L}{R}$ времени.

### Задача 2 (2 балла)
Допустим, мы хотим коммутацией пакетов отправить файл с хоста A на хост Б. Между хостами установлены три
последовательных канала соединения со следующими скоростями передачи данных:
$R_1 = 200$ Кбит/с, $R_2 = 3$ Мбит/с и $R_3 = 2$ Мбит/с.
Сколько времени приблизительно займет передача на хост Б файла размером $5$ мегабайт?
Как это время зависит от размера пакета?

#### Решение
Пусть файл делится ровно на $k$ пакетов, тогда размер одного пакета $\dfrac{40}{k}$, где $40$ - размер файла в Мбит (далее я буду опускать размерность и по умолчанию измерять величины в Мбит, с, Мбит/с).

Назовём хосты так: `клиент --<200 Кбит/c>-- хост 1 --<3 Мбит/c>-- хост 2 --<2 Мбит/c>-- сервер`.

Докажем, что больше одного пакета никогда не будет на одном хосте. В самом деле, клиент отправит один пакет хосту 1 за время $\dfrac{40}{0.2 k} = \dfrac{200}{k}$; хост 1 отправит его хосту 2 за $\dfrac{40}{3 k} = \dfrac{13.33}{k}$ и будет ещё долго ждать следующего пакета, а хост 2 за это время уже успеет передать пакет серверу ($\dfrac{40}{2 k} = \dfrac{20}{k}$) и тоже будет простаивать.

Следовательно, клиент отправит $k-1$ пакетов хосту 1 через время $\dfrac{40}{0.2k}(k-1) = \dfrac{200}{k}(k-1)$. Далее он начнёт передавать последний пакет, и на сервере он окажется через время $\dfrac{40}{0.2k}+\dfrac{40}{3k}+\dfrac{40}{2k} = \dfrac{200}{k} + \dfrac{13.33}{k} + \dfrac{20}{k}$. Итого $\dfrac{200}{k}k + \dfrac{33.33}{k} = 200 + \dfrac{33.33}{k}$. Чем больше пакетов (= чем меньше размер пакета), тем меньше времени будет потрачено на передачу последнего пакета.

### Задача 3 (2 балла)
Предположим, что пользователи делят канал с пропускной способностью $2$ Мбит/с. Каждому
пользователю для передачи данных необходима скорость $100$ Кбит/с, но передает он данные
только в течение $20$ процентов времени использования канала. Предположим, что в сети всего $60$
пользователей. А также предполагается, что используется сеть с коммутацией пакетов. Найдите
вероятность одновременной передачи данных $12$ или более пользователями.

#### Решение
Через канал одновременно могут передавать данные до 20 пользователей. Допустим, что в конкретный момент времени каждый пользователь хочет передать данные с вероятностью $\dfrac{1}{5}$. Тогда вероятность, что 12 или более из них захотят передать данные, равна $\displaystyle{\sum_{i=12}^{60} C_{60}^{i} \cdot \left(\dfrac{1}{5}\right)^{i} \cdot \left(\dfrac{4}{5}\right)^{60-i}}$.

Можно посчитать это с помощью модуля `scipy`:
```python
import scipy.stats as sps

print(1 - sps.binom(60, 1/5).cdf(11))
```
---
`0.5513825262506507`

Вероятность получилась довольно не маленькая.

### Задача 4 (2 балла)
Пусть файл размером $X$ бит отправляется с хоста А на хост Б, между которыми три линии связи и
два коммутатора. Хост А разбивает файл на сегменты по $S$ бит каждый и добавляет к ним
заголовки размером $80$ бит, формируя тем самым пакеты длиной $L = 80 + S$ бит. Скорость
передачи данных по каждой линии составляет $R$ бит/с. Загрузка линий мала, и очередей пакетов
нет. При каком значении $S$ задержка передачи файла между хостами А и Б будет минимальной?
Задержкой распространения сигнала пренебречь.

#### Решение
Пакетов будет $\dfrac{X}{S}$. По формуле из первой задачи, задержка будет равна $\left(\dfrac{X}{S} - 1 + 3\right)\dfrac{80+S}{R}$ = $\left(\dfrac{X}{S} + 2\right)\dfrac{80+S}{R}$. Нужно найти производную этой функции, чтобы выяснить значение $S$, при котором достигается минимум. Она равна $-\dfrac{80X}{S^2 R} + \dfrac{2}{R}$. Ноль производной достигается при $S = \sqrt{40X}$. Следует учесть, что размер файла может не делиться на полученное значение, из-за чего образуется дополнительный неполный пакет размера 80 бит + остаток. Но при больших значениях $X$ этот дополнительный заголовок в 80 бит не будет играть заметную роль.

### Задание 5 (2 балла)
Рассмотрим задержку ожидания в буфере маршрутизатора. Обозначим через $I$ интенсивность
трафика, то есть $I = \dfrac{L a}{R}$.
Предположим, что для $I < 1$ задержка ожидания вычисляется как $\dfrac{I \cdot L}{R (1 – I)}$. 
1. Напишите формулу для общей задержки, то есть суммы задержек ожидания и передачи.
2. Опишите зависимость величины общей задержки от значения $\dfrac{L}{R}$.

#### Решение
1. $\dfrac{I \cdot L}{R (1 - I)} + \dfrac{L}{R} = \dfrac{I \cdot L + (1 - I) \cdot L}{R (1 - I)} = \dfrac{L}{R(1 - I)} = \dfrac{L}{R\left(1-\dfrac{La}{R}\right)} = \dfrac{L}{R - La}$.
2. Пусть $d = \dfrac{L}{R}$. Тогда $I = da$, а общая задержка $\dfrac{d}{1 - da}$. Эта величина увеличивается с увеличением $d$ и уменьшается с уменьшением $d$.
